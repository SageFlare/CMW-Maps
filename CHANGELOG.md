# Changelog

## 0.2.0 (prerelease, multiplayer test)

- Outpost is now a **team objective** map: burn the tents, push the caravan, destroy the barricade, capture the tower and kill the four Mason chieftains. The map name stays `FFA_CMW_Outpost`.
- The objective Blueprints are inside `CMW_Outpost.pak`; no extra objective mod is needed.
- Player score for objective actions (Chivalry 2 score events, or Chivalry 2 default values where CMW had none).
- Needs CMW-Library **0.2.0** (holds exactly the assets Outpost uses).
- Only Outpost is in this release. The 0.1.0 free-for-all maps are not included.

## 0.1.0 (prerelease, dev/test)

- Seven maps as free-for-all maps: Cistern, Courtyard, Frost Peak, Arena, Coldfront, Battlegrounds, Outpost. Needs CMW-Library 0.1.0.
